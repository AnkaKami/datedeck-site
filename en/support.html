Support

Something broken, no code in your inbox, or the gift won’t open? Write to hello@datedeck.love. We reply within a day.

It’s easier from the app: “Contact support” at the bottom of the home screen adds the app and phone version for you.

The code doesn’t arrive

Check Spam and Promotions. The code is valid for an hour, and you can ask for a new one after a minute. If it still doesn’t come, sign in with Apple.

“Gift already opened”

The code works once. If the wrong person opened the gift, the buyer can reissue the code on the gift page: the old one stops working, the deck and collection stay.

Delete my account and data

Write to hello@datedeck.love from your account email and we’ll delete your account, gifts, ideas and photos within 30 days.
